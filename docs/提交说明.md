# AIPet 桌宠 · 提交说明（答辩 / 验收材料）

## 一、项目简介

一款基于 **C++ / Qt 6（Widgets）** 的桌面 AI 陪伴助手，面向大学生日常学习场景。桌宠以二次元少女形象常驻桌面，支持拖拽喂资料、AI 智能总结、突击抽背、任务清单、课表提醒、番茄钟专注与摸鱼小游戏，主打"拟人化交互 + 沉浸式伴学"。

## 二、功能清单（全部已实现并验证）

| 功能 | 说明 |
| --- | --- |
| 拟人化桌宠 | 4 套透明背景 GIF 表情（日常/思考/开心/可爱），双击 Q 弹、转身镜像 |
| **陪伴感打磨（新增 P2）** | ① 拖拽物理感：松手后抛物线减速滑行，撞到屏幕边缘轻微反弹；贴靠屏幕左右边缘自动半透明收缩只露半边脸，鼠标移过去平滑滑出，不挡课件 ② 闲置状态机：30 秒眨眼 → 2 分钟换姿势+碎碎念 → 5 分钟打瞌睡 → 10 分钟趴桌睡觉；学习向碎碎念当天不重复，右键「陪伴频率」三档可调（安静/适中/活泼） ③ 分区点击：摸头（蹭手）/ 戳脸（鼓腮生气）/ 碰手（挥手），各自专属表情+台词 |
| 拖拽式总结 | 支持 PDF/TXT/MD/代码拖拽投喂，AI 提取核心考点 |
| **长文档分段总结（新增）** | 长课件自动按 2000 字分块，逐块 AI 小结，全部完成后合并输出「全文核心总结 + 高频考点清单」；处理中思考脸、每啃完一块眨眼、完成切开心脸；**气泡保持小巧但可在气泡内滚动查看完整总结**，点击互动/空闲闲聊不会覆盖总结内容（总结锁定）；完整版另存档到本机，右键「查看最近总结…」可弹窗查看 |
| 突击抽背 | 基于已吃掉的资料由 AI 出题，弹出输入框作答并判定对错 |
| 番茄钟专注模式 | 25 分钟专注 + 5 分钟休息，右键开始/暂停/结束，专注中不闲聊；完成/休息结束有系统通知 + 提示音 |
| 专注统计 | 近 7 天专注时长柱状图（右键菜单进入），按天持久化 |
| 摸鱼小游戏 | 休息时自动弹出"接星星"小游戏（60 秒限时、漏 10 颗结束、可重玩） |
| 任务清单 / 课表提醒 | 右键菜单管理，到点气泡提醒 |
| **启动欢迎语（新增）** | 每次启动（含开机自启）打招呼：按时间问好（早上好/中午好/晚上好等），结合当天待办任务数与今日专注状态个性化鼓励（如"晚上好！今天还没开始专注，要不要来一轮番茄钟？"） |
| **最近总结持久化（新增）** | 完整总结除带时间戳存档外，另写固定文件 `latest_summary.txt`，**重启程序后右键「查看最近总结…」仍能打开上次的总结全文** |
| **开机自启动（新增）** | 右键 →「开机自启动」勾选即写注册表开机启动项；**随时可取消勾选关闭**（别人也能在菜单里关掉），绿色可逆 |
| **离线 AI 模式（新增 P2 演示加分）** | 右键 →「AI 模式」可切换 **在线（DeepSeek）/ 离线（Ollama）**；离线走本机 Ollama 的 OpenAI 兼容接口（默认 `http://127.0.0.1:11434/v1`，模型默认 `qwen2.5:7b`，可在配置文件 `[api] ollamaUrl/ollamaModel` 改），**演示时拔网线照样总结/抽背**；Ollama 未启动时自动降级为本地速览提示，不崩溃 |
| **学习数据看板 + 成就（新增 P2 演示加分）** | 右键 →「学习看板…」：近 7 天专注柱状图 + 学习统计（喂资料份数 / 抽背次数 / 答对数 / 正确率）+ 成就列表；成就含「初尝甜头（完成第一次番茄钟）」「连续专注 7 天」「喂饱我啦（喂 10 份资料）」「小试牛刀（答对 5 题）」「答题狂魔（抽背 20 次）」，达成时宠物切开心脸+气泡祝贺，看板内 ✔ 标记 |
| **一键导出学习笔记（新增 P2 演示加分）** | 右键 →「导出学习笔记…」：把学习统计 + 全部资料总结全文 + 错题本（抽背答错的题）一键导出为 **Markdown 文件**，可直接粘贴进 Notion / 有道云笔记 |
| 托盘支持 | 常驻托盘图标，右键快捷菜单 |

## 三、运行 / 部署方式

- **可执行文件**：`dist\aipet1.exe`（已用 windeployqt 打包 Qt 运行时，单机免安装，双击即可运行；绿色免安装，可直接拷贝整目录分发）
- 环境要求：Windows 10/11 64 位，无需安装 Qt
- 推荐以"拷贝 `dist` 整个目录"的方式部署到测试机

## 四、API Key 配置（测试人员用自己的 API）

- 程序**不内置任何 API Key**，代码中不写死密钥
- 首次启动会自动弹出「设置 API Key」，或右键桌宠 →「设置 API Key」粘贴
- Key 仅保存在本机配置文件 `%APPDATA%\AIPet\AIPet1.ini` 的 `[api]` 段，不上传、不入库
- 测试人员可随时换成自己的 Key，换完立刻生效

## 五、数据存储说明

本项目为**单机应用，不使用数据库**。所有持久化数据保存在本地 ini 配置文件
`%APPDATA%\AIPet\AIPet1.ini`：

| 数据 | 存储位置 |
| --- | --- |
| API Key | `[api] key=` |
| AI 模式（在线/离线） | `[api] mode=online\|offline`、`[api] ollamaUrl=`、`[api] ollamaModel=` |
| 任务清单 | `[tasks] list=` |
| 课表 | `[schedule] items=` |
| 专注每日累计 | `[focus] daily\yyyyMMdd=` |
| 学习统计（喂资料/抽背/答对） | `[stats] docsFed / quizTaken / quizCorrect / wrongList` |
| 已解锁成就 | `[achievements] list=` |

## 六、测试方法速查

1. **喂资料总结**：把 PDF/TXT 拖到宠物身上，观察"思考 → 眨眼 → 开心"表情链和最终总结
2. **长文档分段总结**：拖入 >2200 字的课件（如 `tests\long_notes.txt`），观察分块进度与合并成果
3. **突击抽背**：喂资料后右键 →「考考我…」，输入答案提交后 AI 判定对错；**答错的题自动进错题本**
4. **番茄钟**：右键 →「开始专注（25 分钟）」；专注完成自动休息 + 通知 + 游戏
5. **学习看板**：右键 →「学习看板…」查看 7 天专注柱状图 + 学习统计 + 成就列表；**完成一次番茄钟即可解锁「初尝甜头」成就**（宠物开心脸祝贺，看板 ✔ 标记）
6. **查看完整总结**：总结内容可直接在气泡内滚动查看（鼠标悬停气泡滚轮滚动），点击桌宠不会覆盖总结内容；也可右键 →「查看最近总结…」弹窗查看全文；**重启程序后仍可查看**（自动读上次的总结存档）
7. **陪伴感**：把宠物拖到屏幕左右边缘 → 自动半透明收缩只露半边脸，鼠标移过去滑出；闲置 30 秒眨眼 / 2 分钟换姿势说学习向碎碎念 / 5 分钟打瞌睡 / 10 分钟趴桌睡觉；点宠物头部摸头、点身体戳脸、点左右手碰手，各有专属反馈；右键 →「陪伴频率」可调碎碎念密度
8. **开机自启动 + 欢迎语**：右键 →「开机自启动」勾选后开机自动运行（取消勾选即关闭）；每次启动自动弹出鼓励式欢迎语（按时间问好 + 当天任务/专注个性化）
9. **离线 AI 模式**：右键 →「AI 模式」→「离线（Ollama）」；演示前先装好 Ollama（`ollama pull qwen2.5:7b`），**现场拔网线后拖资料/考考我仍然工作**（走本机模型）；没装 Ollama 时会自动降级为本地速览提示
10. **导出学习笔记**：右键 →「导出学习笔记…」选择保存位置，生成 Markdown（学习统计 + 全部资料总结 + 错题本），可直接粘贴到 Notion/有道云
11. **演示参数**：
   - `aipet1.exe --autofast`：3 秒专注 + 2 秒休息，快速演示番茄钟全流程
   - `aipet1.exe --autosummary`：自动加载测试长文档演示分段总结
   - `aipet1.exe --autoquiz`：自动演示突击抽背全流程（出题→作答→判定）
   - `aipet1.exe --autoidle=120`：模拟已闲置 2 分钟，立即展示"换姿势+碎碎念"；`--autoidle=610` 展示"趴桌睡觉"
   - `aipet1.exe --autodock`：启动 3 秒后自动贴到屏幕右边缘，展示"半透明收缩只露半边脸"
   - `aipet1.exe --autoboard`：启动 3 秒后自动打开学习看板（快速展示统计与成就）
   - `aipet1.exe --autoexport`：启动后自动把学习笔记导出到桌面 `AIPet学习笔记_验证.md`
   - 以上参数仅用于演示，正常启动不带参数
