# AIPet 桌面陪伴助手

一款基于 C++/Qt 的拟人化桌面 AI 学习伴侣：以桌宠形象承载 AI 能力，把**资料总结、番茄专注、陪伴激励**放进桌面一角，让学习有反馈、有陪伴、可沉淀。

## 功能特性

- **拖拽式总结**：把 PDF / 文档直接拖给桌宠，AI 自动提取核心摘要与高频考点。
- **长文档分段啃读**：按约 2000 字分块逐块生成小结，再合并为「全文核心总结 + 高频考点清单」，几十页课件不丢后半段；处理过程通过表情反馈进度（思考脸 → 逐块眨眼 → 完成开心脸）。
- **突击抽背**：右键菜单「考考我」，宠物根据已吃掉的资料自动出题，答错自动收入错题本。
- **番茄钟专注模式**：25 分钟专注 + 5 分钟休息，结束有系统通知音与右下角气泡提醒；休息时自动弹出「接星星」摸鱼小游戏。
- **学习看板与成就系统**：近 7 天专注时长柱状图、喂资料/抽背正确率统计、成就解锁（如「连续专注 7 天」「喂完 10 份资料」）。
- **一键导出学习笔记**：总结 + 考点 + 错题导出为 Markdown，可直接粘贴到 Notion / 有道云笔记。
- **离线 AI 模式**：在线 DeepSeek 与本地 Ollama（OpenAI 兼容接口）右键一键切换，断网也能演示。
- **陪伴感打磨**：
  - 拖拽松手抛物线减速 + 贴边自动半透明收缩露半脸，鼠标移过去滑出；
  - 闲置状态机：30 秒眨眼、2 分钟换姿势、5 分钟打瞌睡、10 分钟趴桌睡觉；
  - 学习向随机碎碎念（当天不重复，频率可调）；
  - 分区点击互动：摸头会蹭手、戳脸会鼓腮生气、碰手会挥手。
- **日常辅助**：任务清单、课表提醒、启动欢迎语（时间问候 + 今日任务提醒）、开机自启（设置中可关闭）、总结与错题本地持久化。

## 技术架构

```
交互层 · 桌宠窗口
  拖拽投喂 / 右键菜单 / 气泡对话 / 表情互动
        ↓
功能引擎
  分段总结 / 突击抽背 / 番茄钟 / 看板与成就 / 导出笔记
        ↓
AI 适配层 · 双通道
  在线 DeepSeek API  ⇄  离线 Ollama 本地模型
```

技术栈：C++17 · Qt 6.12 Widgets · QNetworkAccessManager · 无第三方运行时依赖。

## 快速开始

### 构建要求

- Qt 6.12+（MinGW 64-bit）
- qmake + mingw32-make（或 Qt Creator）

### 构建

```bash
cd AIPet
qmake AIPet.pro
mingw32-make
```

构建产物为 `aipet1.exe`（若需脱离 Qt 环境分发，用 `windeployqt --release` 打包 dist 目录）。

### 运行

双击 `aipet1.exe` 即可，桌宠会出现在屏幕右下角。

## 使用说明

| 操作 | 说明 |
|---|---|
| 拖拽 PDF/文档到宠物身上 | 触发 AI 总结（长文档自动分段） |
| 右键点击宠物 | 功能菜单：切换状态 / 陪伴频率 / 开始专注 / 考考我 / 任务清单 / 课表提醒 / 学习看板 / 导出笔记 / AI 模式 / 设置 / 退出 |
| 单击不同部位 | 摸头 / 戳脸 / 碰手，触发不同表情与台词 |
| 专注结束 | 系统通知音 + 右下角气泡；休息自动弹出接星星小游戏 |

### AI 配置

- **在线模式**：在设置中填入 DeepSeek API Key（仅保存在本机 `%APPDATA%\AIPet\AIPet1.ini`，不入库不入代码）。
- **离线模式**：本机运行 Ollama 服务（默认 `http://127.0.0.1:11434/v1`，模型默认 `qwen2.5:7b`），右键「AI 模式 → 离线」即可切换，断网可用。

## 自动化演示参数

便于验收/答辩现场一键演示，无需手动操作：

| 参数 | 效果 |
|---|---|
| `--autofast` | 快速走完欢迎语 + 抽背完整流程 |
| `--autosummary` | 自动喂入 `tests/long_notes.txt` 触发分段总结 |
| `--autoquiz` | 自动喂入 `tests/demo_notes.txt` 并自动作答 |
| `--autoidle=120/610` | 自动触发闲置碎碎念 / 趴桌睡觉 |
| `--autodock` | 自动演示贴边收缩 |
| `--autoboard` | 3 秒后打开学习看板 |
| `--autoexport` | 4 秒后导出学习笔记到桌面 |

## 目录结构

```

├── aipet1.pro / aipet1.qrc        # Qt 工程与资源
├── main.cpp / desktoppet.*        # 主程序与桌宠窗口
├── pdfextract.*                   # PDF 文本提取
├── stargame.*                     # 接星星小游戏
├── statsdialog.*                  # 学习看板与成就
├── resources/
│   ├── pet/                       # 桌宠表情 GIF（透明）
│   └── sound/                     # 提示音
├── tests/                         # 测试样本与文档
└── docs/
    ├── 提交说明.md
    └── AIPet数据库导出.sql        # SQLite 结构示例（API Key 已脱敏）
```

## 数据存储

- 配置文件：`%APPDATA%\AIPet\AIPet1.ini`（AI Key、模式、统计、任务、课表等）
- 总结存档：`latest_summary.txt`（重启后仍可查看最近总结）
- 数据表结构：见 `docs/AIPet数据库导出.sql`
