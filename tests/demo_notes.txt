数据结构期末复习笔记（重点版）
第一章 绪论
1.1 数据结构定义：数据结构是相互之间存在一种或多种特定关系的数据元素的集合。
1.2 考点：逻辑结构分为线性结构（线性表、栈、队列、串）和非线性结构（树、图）。
1.3 考点：存储结构（物理结构）分为顺序存储、链式存储、索引存储、散列存储。
1.4 重点：时间复杂度用大O记号表示，常见复杂度 O(1) < O(logn) < O(n) < O(nlogn) < O(n^2)。
第二章 线性表
2.1 定义：线性表是具有相同数据类型的n个数据元素的有限序列。
2.2 重点：顺序表插入/删除需移动大量元素，时间复杂度 O(n)。
2.3 考点：链表插入删除只需修改指针，时间复杂度 O(1)（已知位置时）。
2.4 结论：顺序表适合查找频繁，链表适合插入删除频繁。
第三章 栈和队列
3.1 定义：栈是只允许在一端进行插入和删除的线性表，先进后出（FILO）。
3.2 考点：队列是先进先出（FIFO）的线性表。
3.3 重点：栈的应用：括号匹配、表达式求值、递归、函数调用。
3.4 考点：循环队列判满公式 (rear+1)%MaxSize == front。
第四章 树与二叉树
4.1 定义：树是n个结点的有限集。二叉树每个结点至多有两棵子树。
4.2 重点：满二叉树、完全二叉树的概念。
4.3 考点：二叉树第i层至多有 2^(i-1) 个结点，深度为k的二叉树至多有 2^k - 1 个结点。
4.4 重点：遍历方式：先序（根左右）、中序（左根右）、后序（左右根）、层序。
4.5 结论：已知中序 + 先序或后序可唯一确定二叉树。
4.6 考点：二叉排序树（BST）左子树<根<右子树。
第五章 图
5.1 定义：图由顶点集V和边集E组成。
5.2 重点：图的遍历：深度优先搜索（DFS，用栈）、广度优先搜索（BFS，用队列）。
5.3 考点：最小生成树算法：Prim、Kruskal。
5.4 考点：最短路径：Dijkstra（单源）、Floyd（所有顶点对）。
第六章 查找
6.1 考点：顺序查找平均查找长度 (n+1)/2。
6.2 重点：二分查找要求线性表有序且顺序存储，时间复杂度 O(logn)。
6.3 考点：散列表（哈希表）冲突处理：开放定址法、链地址法。
第七章 排序
7.1 重点：稳定排序：冒泡、插入、归并、基数；不稳定：选择、快排、希尔、堆。
7.2 考点：快速排序平均时间复杂度 O(nlogn)，最坏 O(n^2)。
7.3 重点：堆排序时间复杂度 O(nlogn)，空间复杂度 O(1)。
7.4 结论：n较大且要求稳定用归并排序。
总结：数据结构核心是逻辑结构+存储结构+算法设计，考试重点掌握各结构的增删查改时间复杂度。
